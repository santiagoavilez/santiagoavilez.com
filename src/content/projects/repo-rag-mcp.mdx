## Repo RAG MCP Server

MCP server that indexes an organization's repositories — code, commits, PRs and docs — so developers can query the codebase from AI assistants.

- Indexes code, commit history, pull requests and markdown docs across an organization's repos
- Exposes retrieval as MCP tools usable from Claude Code, Cursor and other MCP clients
